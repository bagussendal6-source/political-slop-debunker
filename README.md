# Political Slop Debunker

A Chrome extension (Manifest V3) that fact-checks claims in Indonesian political YouTube videos and shows the results, with sources, in a side panel.

- Reads the video transcript in windows and picks out checkable claims.
- Verifies each claim with web search and cites sources.
- Flags reasoning and bias patterns (for example inconsistency, shifting targets, one-sided data) using a fixed set of flags.

**Status:** working prototype (v0.1.0). Planned improvements and what is already done are in `IMPROVEMENT_PLAN.md` (written in Indonesian).

**Install (development):** open `chrome://extensions`, turn on Developer mode, choose "Load unpacked" and select this folder.
